# David Delannoy Développement — site vitrine

Site statique publié avec GitHub Pages. Aucun serveur applicatif n'est requis.

## Pages actives
- `index.html` : accueil
- `presentation.html` : expertise et prestations
- `projets.html` : exemples de projets
- `contact.html` : contact direct par email ou téléphone
- `rgpd.html` : mentions légales et politique de confidentialité

## Compatibilité avec les anciennes URL
Les fichiers `flux.html`, `solutions.html`, `suivi-client.html` et les anciennes pages `portfolio-*.html` sont conservés uniquement comme redirections vers `projets.html`, afin de ne pas casser d'anciens liens ou favoris.

## Ressources
- `styles/style.scss` : source de styles
- `styles/style.css` : feuille utilisée par le site
- `js/script.js` : menu mobile et contextualisation des demandes de contact
- `images/` : logo et favicon utilisés par le site
- `google1b8ab20e3a7cbabe.html` : fichier de vérification Google à conserver

## Contact
Les visiteurs contactent directement l'entreprise par email ou téléphone.

## Maintenance
Après toute évolution, vérifier les liens locaux, les ancres, le rendu ordinateur/mobile et la cohérence de la page `rgpd.html` avec les services réellement utilisés.
